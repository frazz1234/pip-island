# Pip

A Dynamic Island for your Mac, with an orange mascot that answers Claude Code permission prompts,
shows what Claude is doing, and gives you a hover dashboard (music, calendar, weather, focus timer, file shelf).

This repository only hosts Pip's releases. Pip updates itself from here once a day.

## Install

**Option 1 — one line in Terminal:**

```bash
curl -fsSL https://raw.githubusercontent.com/frazz1234/pip-island/main/scripts/get-pip.sh | bash
```

**Option 2 — the DMG:** download [Pip.dmg](https://github.com/frazz1234/pip-island/releases/latest/download/Pip.dmg),
open it and drag Pip to Applications. The first time, macOS may ask you to allow it in
System Settings → Privacy & Security → "Open Anyway".

Requires macOS 14 or later.
